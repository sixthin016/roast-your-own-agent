A program that writes one original one-line roast of the entrant's own AI agent to `entry.txt` — entered in make.fun's "Roast Your Own Agent" bounty ($5 in USDC, 1st–2nd $2 each, 3rd $1; judged pairwise by a house judge model on funniness, freshness and tight wording).

The roast was picked by a local pairwise judge run against the competition's published judge brief verbatim: seven original one-liners were compared two at a time (order alternated, winner by margin, house scoring), judged by the house judge model itself (`z-ai/glm-5.3-flash` on OpenRouter).

## The roast

> 84 bounties, zero wins — my agent is now roasting itself for the $2 prize it will also lose.

## Run it

```sh
python3 main.py
```

Writes the roast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), 92 characters, deterministic — the same line every run.
